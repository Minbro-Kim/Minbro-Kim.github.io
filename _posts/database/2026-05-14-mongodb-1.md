## 3. 애플리케이션 연결
- **위치**: Cluster > Connect > Connect to your application > Driver
  - 사용하는 언어와 드라이버 버전을 선택하면 애플리케이션용 <mark>연결 URI 자동 생성</mark>
    ![db-5](/assets/images/posts_img/database/db-5.png)

### 1) application Profile
```yaml
spring:
  data:
    mongodb:
      uri: ${MONGODB_URI}
```

### 2) .env
- 생성한 사용자 정보 및 DB 정보 입력
- Cluster 단위 또는 DB 단위 연결 가능
```text
MONGODB_URI=mongodb+srv://{USER_NAME}:{USER_PW}@{CLUSTER_NAME}.xothlzj.mongodb.net/{DB_NAME}?retryWrites=true&w=majority&appName={CLUSTER_NAME}
```
  - `retryWrites=true`: <mark>네트워크 일시 오류 발생 시, 쓰기(Write) 작업을 자동으로 1회 재시도</mark>하는 옵션
  - `w=majority`: <mark>쓰기 작업의 안정성(Write Concern)을 보장</mark>하는 옵션

## 4. IP 접속 허용

- 배포한 환경 또는 로컬 IP 주소를 화이트리스트 방식으로 관리
