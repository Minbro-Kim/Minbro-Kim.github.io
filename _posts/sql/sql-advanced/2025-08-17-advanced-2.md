## 집합 연산자(Set Operator) 개요
- 집합연산자를 이용하여 조인없이 두 개 이상의 테이블에서 연관된 데이터 조회
- 여러 개의 결과 집합 간의 연산을 통해 결합 → 두 개 이상의 질의 결과를 하나의 결과로 만듦
- <mark>ORDER BY 절은 집합 연산을 적용한 최종 결과에 대한 정렬 수행</mark>

### 사용목적
- 서로 다른 테이블에서 반환된 결과를 하나의 결과로 합침
- 동일 테이블에서 서로 다른 질의에 따른 결과를 합침
- 튜닝 관점에서 실행계획 분리

### 집합 연산자를 사용하기 위한 조건
- SELECT 절의 칼럼 수 동일
- SELECT 절의 동일 위치에 존재하는 칼럼의 데이터 타입 동일

### 집합 연산자 종류

- **UNION**
    - 개별 SQL 문의 결과에 대한 합집합 연산 수행
    - 모든 중복된 행은 하나의 행으로 통합
    - 동일 테이블이면 IN 또는 OR을 이용한 것으로 작성 가능
    <div class="col-2-container align-center" markdown="1">
    <div class="col-2-item" markdown="1">

    ```plsql
    --UNION을 이용하여 작성 
    SELECT PLAYER_NAME, TEAM_NAME
    FROM 선수
    WHERE TEAM_NAME = '카라스노'
    UNION
    SELECT PLAYER_NAME, TEAM_NAME
    FROM 선수
    WHERE TEAM_NAME = '아오바죠사이'
    ORDER BY 1;
    ```

    ```plsql
    --IN을 이용하여 작성
    SELECT DISTINCT PLAYER_NAEM, TEAM_NAME
    FROM 선수
    WHERE TEAM_NAME IN ('카라스노','아오바죠사이')
    ORDER BY 1;
    ```
  
    </div>

    - 중복을 제외해야 함으로 DISTINCT 추가

- **UNION ALL**
    - <mark>개별 SQL 문의 결과에 대한 합집합 연산 수행</mark>
    - <mark>모든 중복된 행을 그대로 표시 → 중복된 행이 없으면 UNION과 동일한 결과</mark>
    - 질의 결과가 상호 배타적일 때 사용 → 성능을 높이기 위해(중복행 탐색 필요X)
    - 동일 테이블이면 IN 또는 OR을 이용한 것으로 작성 가능

    <div class="col-2-container align-center" markdown="1">
    <div class="col-2-item" markdown="1">

    ```plsql
    SELECT 'P' 구분코드, PLAYER_NAME, TEAM_NAME
    FROM 선수
    WHERE TEAM_NAME = '카라스노'
    UNION ALL
    SELECT 'T', PLAYER_NAME, TEAM_NAME
    FROM 선수
    WHERE PLAYER_NAME = '히나타'
    ORDER BY 1;
    ```
    
    </div>
    <div class="col-2-item" markdown="1">

    ![image.png](/assets/images/posts_img/sql/sql-advanced/sql-11.png)

    - 중복된 열 출력
    - 구분코드로 결과 행 구분
    - HEADING에 첫번째 SQL문의 ALIAS가 사용됨(구분코드)
    </div>
    </div>
  
    - 증복된 행 조회

    ```plsql
    SELECT PLAYER_NAME, TEAM_NAME, COUNT(*) AS "중복 수"
    FROM (
        SELECT PLAYER_NAME, TEAM_NAME
        FROM 선수
        WHERE TEAM_NAME = '카라스노'
        UNION ALL
        SELECT PLAYER_NAME, TEAM_NAME
        FROM 선수
        WHERE PLAYER_NAME = '히나타')
    GROUP BY PLAYER_NAME, TEAM_NAME
    HAVING COUNT(*) > 1
    ORDER BY 1;
    ```
  
    ![image.png](/assets/images/posts_img/sql/sql-advanced/sql-12.png)

- **INTERSECT**
    - 개별 SQL 문의 결과에 대해 교집합 연산 수행
    - 모든 중복된 행은 하나의 행으로 통합
    - IN/ EXISTS 서브쿼리/ 논리연산자로 변경 가능
    - MY SQL: 곱집합 연산자 없음
  
    <div class="col-2-container align-center" markdown="1">
    <div class="col-2-item" markdown="1">

    ```plsql
    SELECT SINIGAMI_NAME, DEPARTMENT, HEIGHT
    FROM  호정대
    WHERE HEIGHT >= 180
    INTERSECT
    SELECT SINIGAMI_NAME, DEPARTMENT, HEIGHT
    FROM 호정대
    WHERE DEPARTMENT = '11번대'
    ORDER BY 2;
    ```
    
    </div>

- **EXCEPT**
    - 개별 SQL 문의 결과에 대해 차집합 연산 수행
    - 모든 중복된 행은 하나의 행으로 통합
    - 집합 순서에 따라 결과 바뀜
    - NOT IN/ NOT EXISTS 서브쿼리/ 논리 연산자로 변경 가능
    - Oracle: MINUS
    - SQL Server: EXCEPT
    - MY SQL: 차집합 연산자 없음

    <div class="col-2-container align-center" markdown="1">
    <div class="col-2-item" markdown="1">

    ```plsql
    SELECT SINIGAMI_NAME, DEPARTMENT, HEIGHT
    FROM  호정대
    WHERE HEIGHT >= 180
    MINUS
    SELECT SINIGAMI_NAME, DEPARTMENT, HEIGHT
    FROM 호정대
    WHERE DEPARTMENT = '11번대'
    ORDER BY 2;
    ```
