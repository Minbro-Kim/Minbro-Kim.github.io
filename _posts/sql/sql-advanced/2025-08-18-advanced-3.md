## 1. 데이터 분석 개요

- 데이터 분석을 위한 ANSI/ISO SQL 표준 정의 함수
    - **(GROUP) AGGREGATE FUNCTION**
        - GROUP FUNCTION의 한 부분으로 분류 가능
        - COUNT, SUM, AVG 등의 집계함수 포함
    - **GROUP FUNCTION**
        - 소계, 합계 등의 여러 레벨의 결산을 위한 함수
        - GROUPING함수와 CASE함수를 추가 이용하여 포맷 지정 가능
        - ROLLUP, CUBE, GROUPING SETS 함수 포함
    - **WINDOW FUNCTION**
        - 분석 함수(ANALYTIC FUNCTION)이나 순위 함수(RANK FUNCTION)으로도 부름
        - 데이터 웨어 하우스에서 발전한 기능

## 2. ROLLUP  함수

- 소그룹 간의 소계 계산 → <mark>괄호를 묶은 집합별로 집계를 구할 수 있음</mark> `ROLLUP((CO1,CO2), CO3)`
- GROUP BY의 확장된 형태
- 병렬 수행 → 효율적
- 계층적 분류(시간, 지역 등)를 포함한 데이터 집계에 적합 → 인수 순서 변경 시 결과 달라짐
- Grouping Columns의 List(그룹핑 기준 칼럼 목록)은 소계(Subtotal) 생성을 위해 사용
- **<mark>Subtotal Level = 그룹핑 칼럼 수 + 1</mark>**
- UNION ALL로 구현(테이블에 여러 번 액세스 필요)보다 수행 속도, 자원 사용률, 가독성 개선

3. **<mark>ROLLUP 함수</mark>**
    - <mark>3개의 LEVEL 집계 생성(2개의 그룹핑 컬럼-팀명, 포지션 +1= 3)</mark>
        - <mark>L1: GROUP BY 수행 시 생성되는 표준 집계(13건)</mark>
        - <mark>L2: 팀명별 모든 포지션의 SUBTATAL(3건)</mark>
        - <mark>L3: GRAND TOTAL(마지막행, 1건)</mark>
    - 계층(LEVEL) 간 집계에서는 정렬(L1→L2→L3)
        - 계층 내 정렬 X → ORDER BY 사용

    ```plsql
    SELECT TEAM_NAME, POSITION, 
            AVG(HEIGHT) AS 평균키, 
            COUNT(*) AS 인원
    FROM 선수
    GROUP BY ROLLUP (TEAM_NAME, POSITION);
    ```

5. **<mark>GROUPING 함수</mark>**
    - <mark>집계 레코드 구분을 위해 사용</mark>
    - <mark>ROLLUP이나 CUBE에 의해 소계가 계산된 결과에 GROUPING(EXPR) = 1 표시</mark>
    - <mark>해당 행에서 EXPR 컬럼이 실제 그룹핑 값으로 사용 → GROUPING(EXPR) = 0</mark>

      → 전체 합계는 모두 1

    ```plsql
    SELECT TEAM_NAME, GROUPING(TEAM_NAME) AS TNAME_GRP,
            POSITION, GROUPING(POSITION) AS POSITION_GRP,
            AVG(HEIGHT) AS 평균키, 
            COUNT(*) AS 인원
    FROM 선수
    GROUP BY ROLLUP (TEAM_NAME, POSITION)
    ORDER BY TEAM_NAME, POSITION;
    ```
    
    ![image.png](/assets/images/posts_img/sql/sql-advanced/sql-19.png)

6. **GROUPING + CASE/DECODE**
    - 집계 레코드에 원하는 문자열을 지정하여 가독성↑
        - GROUPING(EXPR) = 1 → 소계
        - GROUPING(EXPR) = 0 → 일반

    ```plsql
    SELECT CASE GROUPING(TEAM_NAME) WHEN 1 THEN '모든 팀' 
                    ELSE TEAM_NAME END AS 팀명,
            CASE GROUPING(POSITION) WHEN 1 THEN '모든 포지션' 
                    ELSE POSITION END AS 포지션,
            AVG(HEIGHT) AS 평균키, 
            COUNT(*) AS 인원
    FROM 선수
    GROUP BY ROLLUP (TEAM_NAME, POSITION)
    ORDER BY TEAM_NAME, POSITION;
    ```

    ```plsql
    SELECT DECODE(GROUPING(TEAM_NAME), 1,'모든 팀' ,TEAM_NAME) AS 팀명,
            DECODE(GROUPING(POSITION), 1,'모든 포지션',POSITION) AS 포지션,
            AVG(HEIGHT) AS 평균키, 
            COUNT(*) AS 인원
    FROM 선수
    GROUP BY ROLLUP (TEAM_NAME, POSITION)
    ORDER BY TEAM_NAME, POSITION;
    ```

8. **ROLLUP 함수 결합 칼럼 사용**
    - `ROLLUP(C1, (C2,C3))` : 여러 칼럼을 하나의 집합 칼럼으로 간주

      → 괄호 내 칼럼별 집계X
   
    ```plsql
    SELECT DECODE(GROUPING(TEAM_NAME), 1,'모든 팀' ,TEAM_NAME) AS 팀명,
            DECODE(GROUPING(POSITION), 1,'모든 포지션',POSITION) AS 포지션,
            AVG(HEIGHT) AS 평균키, 
            COUNT(*) AS 인원
    FROM 선수
    GROUP BY ROLLUP((TEAM_NAME,POSITION))
    ORDER BY TEAM_NAME, POSITION;
    ```

## 3. CUBE 함수

- ROLLUP과 달리 CUBE는 <mark>결합 가능한 모든 값에 대해 다차원 집계 생성</mark>

  → <mark>Subtotal Level = 2^그룹핑 칼럼 수</mark>

- 내부적으로 Grouping Columns의 순서를 바꿔 쿼리 추가 수행

  → 중복 생성된 Grand Total의 제거 필요 → ROLLUP에 비해 연산↑

- 인수간 평등한 관계 → 인수 순서가 바뀌어도 결과 동일(정렬은 다름)
- <mark>괄호를 묶은 집합별로 집계를 구할 수 있음</mark> `CUBE((CO1,CO2), CO3)`
- UNION ALL로 구현(테이블에 여러 번 액세스 필요)보다 수행 속도, 자원 사용률, 가독성 개선

```plsql
SELECT DECODE(GROUPING(TEAM_NAME), 1,'모든 팀' ,TEAM_NAME) AS 팀명,
        DECODE(GROUPING(POSITION), 1,'모든 포지션',POSITION) AS 포지션,
        AVG(HEIGHT) AS 평균키, 
        COUNT(*) AS 인원
FROM 선수
GROUP BY CUBE(TEAM_NAME,POSITION)
ORDER BY TEAM_NAME, POSITION;
```

## 4. GROUPING SETS 함수

- 다양한 소계 집합 생성
- 인수들이 평등한 관계이므로 인수의 순서가 바뀌어도 결과가 같음
- 괄호를 묶은 집합별로 개별 집계를 구할 수 있음 `GROUPING SETS((CO1,CO2), (CO1,CO3))`

  → CO1,CO2로 그룹핑  결과 `UNIONALL` CO1,CO3로 그룹핑 결과

- UNION ALL로 구현(테이블에 여러 번 액세스 필요)보다 수행 속도, 자원 사용률, 가독성 개선

```plsql
SELECT DECODE(GROUPING(TEAM_NAME), 1,'모든 팀' ,TEAM_NAME) AS 팀명,
        DECODE(GROUPING(POSITION), 1,'모든 포지션',POSITION) AS 포지션,
        AVG(HEIGHT) AS 평균키, 
        COUNT(*) AS 인원
FROM 선수
GROUP BY GROUPING SETS(TEAM_NAME,POSITION)
ORDER BY TEAM_NAME, POSITION;
```

![image.png](/assets/images/posts_img/sql/sql-advanced/sql-25.png)

```plsql
SELECT DECODE(GROUPING(TEAM_NAME), 1,'모든 팀' ,TEAM_NAME) AS 팀명,

        COUNT(*) AS 인원
```
