## 1. ORDER BY 정렬

- `ORDER BY 칼럼/표현식 [ASC|DESE]`조회한 데이터를 특정 칼럼 기준으로 정렬·출력하는데 사용
- 칼럼명 대신 SELECT절에 사용한 ALIAS명 또는 칼럼 순서를 나타내는 정수 사용 가능
- <mark>기본 오름차순</mark>
- <mark>SQL 문장 마지막에 위치</mark>
- <mark>SELECT 절에 없는 칼럼 사용 가능</mark>
    - DISTINCT 지정, GROUP BY 절(다른 집계함수는 가능), 서브쿼리, UNION 연산자를 포함하는 경우

      → SELECT 목록에 포함되어야 함

- 두 가지 정렬방식
    - `ASC(Ascending)`: 오름차순 정렬(기본 값)
        - 숫자 → 작은 값부터 출력
        - 날짜 → 가장 빠른 값부터 출력
        - NULL값 → Oracle: NULL이 가장 큰 값, SQL Server, MySQL: NULL이 가장 작은 값
    - `DESC(Descending)`: 내림차순 정렬
    
<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
SELECT SINIGAMI_NAME 이름, HEIGHT 신장
FROM 호정대
ORDER BY 신장 DESC, 1;
```

- 키로 내림차순 정렬 후, 동일 값에 대해서 이름으로 오름차순 정렬 ⇒ 이치고 → 히사기
- ALIAS명과 칼럼 순서 사용

## 2. SELECT 문장 실행 순서

- SELECT 문장 수행 단계
    - 옵티마이저가 SQL 문장의 SYNTAX, SEMANTIC 에러 점검 순서와 동일
        - ex. FROM절에 정의되지 않은 칼럼은 다른 절에 사용 시 에러
    - <mark>옵티마이저가 SQL문장을 해석하는 논리적 순서(물리적 순서X)</mark>
        - 물리적 순서 → 실행계획으로 정해짐

- 그룹핑(ORDER BY)에서 새로운 집합이 생성

  → 이후에 수행되는 SELECT, ORDER BY에서 그룹핑에 해당하지 않는 개별 칼럼 사용 불가

```plsql
FROM 호정대
GROUP BY DEPARTMENT
HAVING DEPARTMENT IS NOT NULL
ORDER BY MIN(HEIGHdT);
```
