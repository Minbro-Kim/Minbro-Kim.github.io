## 1. SELECT

- **ALL**
    - 중복된 데이터도 모두 출력
    - <mark>생략가능(Default)</mark>

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">


  ```sql
  SELECT DEPARTMENT
  FROM 호정대;
  ```


</div>

  ![image.png](/assets/images/posts_img/sql/sql-basic/sql-5.png)

- **DISTINCT 옵션**
    - 중복된 데이터가 있을 경우 <mark>1건으로 처리</mark>하여 출력
  
<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">


  ```sql
  SELECT DISTINCT DEPARTMENT
  FROM 호정대;
  ```

</div>
<div class="col-2-item" markdown="1">

  ![image.png](/assets/images/posts_img/sql/sql-basic/sql-6.png)

- **애스더리스크(*)**
    - 모든 칼럼 정보

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

  ```sql
  SELECT *
  FROM 호정대;
  ```

</div>
<div class="col-2-item" markdown="1">

  ![image.png](/assets/images/posts_img/sql/sql-basic/sql-7.png)

- **ALIAS(별명) 부여**
    - 칼럼명 바로 뒤에 위치
    - `as/AS` 키워드 사용 가능(가독성 측면에서 사용 권고)
    - 공백, 특수문자, 대소문자 구분 → 이중 인용부호(””) 사용

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

  ```sql
  SELECT SINIGAMI_ID AS 사신번호,
        SINIGAMI_NAME AS 이름, 
        DEPARTMENT AS "소속 호정대"
  FROM 호정대;
  ```

</div>

## 2. 산술 연산자와 합성 연산자

- **산술 연산자**
    - NUMBER와 DATE 자료형에 적용
    - 사칙연산과 동일
    - 괄호를 이용하여 우선순위 표기
        - <mark>우선순위: () →  *  →  /  →  +  →  -</mark>
    - 산술 연산이나 함수 사용 시, 칼럼 레이블 길이를 고려하여 ALIAS 부여

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

  ```sql
  SELECT SINIGAMI_NAME AS 이름,
        HEIGHT-WEIGHT AS "키-몸무게"
  FROM 호정대;
  ```


</div>
<div class="col-2-item" markdown="1">

![image.png](/assets/images/posts_img/sql/sql-basic/sql-9.png)

</div>
</div>

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

  ```plsql
  SELECT SINIGAMI_NAME 이름,
         ROUND(WEIGHT/((HEIGHT/100)*(HEIGHT/100)), 2) BMI
   FROM 호정대;
  ```

  - `ROUND()` : 반올림을 위한 내장함수


</div>
<div class="col-2-item" markdown="1">

  ![image.png](/assets/images/posts_img/sql/sql-basic/sql-10.png)

</div>
</div>


- **합성 연산자(CONCATENATION)**
    - 함수 사용 가능
    - 칼럼과 문자 또는 다른 칼럼과 연결하여 새로운 칼럼 생성
    - Oracle: `||` or `CONCAT(string1, string2)`
    - SQL Server: `+` or  `CONCAT(string1, string2, ... strn)`
    - My SQL: `CONCAT(string1, string2,...strn)`

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

  ```sql
  SELECT DEPARTMENT || '소속의 ' || SINIGAMI_NAME || '의 신체정보: 키-' || 
          HEIGHT || ' 몸무게-' || WEIGHT AS "13호정대 정보"
  FROM 호정대;
  ```
