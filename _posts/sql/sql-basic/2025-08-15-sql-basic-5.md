## 1. 집계 함수(Aggregate Function)

- 여러 행들의 그룹이 모여 <mark>그룹당 하나의 결과 반환(다중 행 함수)</mark>
- GROUP BY 절은 행들을 소그룹화
- `SELECT` 절, `HAVING` 절, `ORDER BY` 절에 사용 가능<mark>(WHERE 절에 사용 불가)</mark>
- 옵션
    - `ALL`: DEFAULT로 생략 가능
    - `DISTINCT`: 같은 값을 하나의 데이터로 처리
- 주요 집계 함수 종류

    | COUNT(*)                          | NULL 값을 포함한 행의 수 출력                  |
    |-----------------------------------|--------------------------------------|
    | COUNT(표현식)                        | 표현식의 값이 NULL 값인 것을 제외한 행 수 출력        |
    | SUM([DISTINCT\|ALL] 표현식)          | 표현식의 NULL 값을 제외한 합계 출력               |
    | AVG([DISTINCT \|ALL] 표현식)         | 표현식의 NULL 값을 제외한 평균 출력               |
    | MAX([DISTINCT\|ALL] 표현식)          | 표현식의 최댓값 출력<br>(문자, 날짜 데이터 타입도 사용 가능) |
    | MIN([DISTINCT\|ALL] 표현식)          | 표현식의 최솟값 출력                          |
    | STDDEV([DISTINCT\|ALL] 표현식)       | 표현식의 표준 편차 출력                        |
    | VARIANCE/VAR([DISTINCT\|ALL] 표현식) | 표현식의 분산 출력                           |

    ```sql
            COUNT(DEPARTMENT) 부대소속행, 
            MAX(HEIGHT) 최대키, 
            ROUND(AVG(HEIGHT),2) 평균키
    FROM 호정대;
    ```

## 2. GROUP BY 절

- WHERE 절 뒤에 위치
- 데이터를 소그룹으로 나눠 항목별 통계 정보를 얻기 위해 사용
- <mark>ALIAS 명 사용 불가 (SELECT 절에서 정의된 것 재활용 불가)</mark>
- <mark>WHERE 절 수행 이후 수행됨</mark>
- 정렬을 위해서는 `ORDER BY` 절 사용 필요

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```sql
SELECT DEPARTMENT 부대, AVG(HEIGHT) 평균키
FROM 호정대
GROUP BY DEPARTMENT;
```

## 3. HAVING 절

- <mark>GROUP BY 절 뒤에 위치</mark>(Oracle은 GROUP BY절과 바꿔도 오류 X)
- <mark>WHERE 절(개별 행에 적용)은 집계함수 사용 불가</mark> → HAVING절(집합 행에 적용)을 통해 GROUP BY 절의 기준 항목이나 소그룹의 집계함수를 이용한 조건 표시
    - WHERE 절에서 행 제외가 가능한 경우, WHERE 절에서 구현하는 것이 계산 양을 줄일 수 있음
    - WHERE 절과 달리 HAVING 절은 데이터 변경은 없고 출력 레코드 개수만 변경
- 소그룹 중 HAVING 절에서 제한 조건을 두어 조건을 만족하는 내용만 출력

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```sql
SELECT DEPARTMENT AS 부대, AVG(HEIGHT) 평균키
FROM 호정대
GROUP BY DEPARTMENT
HAVING AVG(HEIGHT) > 180;
```

## 4. CASE 표현을 활용한 월별 데이터 집계

- `CASE()`/`DECODE` ~ `GROUP BY` → 집계 보고서를 만드는 유용한 기법
    - 월을 CASE로 구분
    - 부서를 GROUP BY로 묶음

## 5. 집계 함수와 NULL 처리

- NULL을 다른 값으로 처리하기 위해 다중 행 함수 내에` NVL`/`ISNULL`을 사용하면 부하 발생 → 사용X
- CASE나 DECODE를 다중  행 함수에 사용할 때에서 ELSE나 기본 값을 부여하면 부하 발생 → 작성하지 않고 NULL로 남겨 둠

        ⇒ NULL은 집계함수에서 자동 제외

  - `SUM(NVL(SAL,0))` X → `NVL(SUM(SAL),0)`
