## 1. WHERE 조건절 개요

- 원하는 자료만 검색 가능
- 두 개 이상의 테이블에 대한 조인 조건을 기술하거나 결과를 제한하기 위한 조건 기술
- WHERE 절에 조건이 없는 FTS(Full Table Scan)은 시스템 사용↑ → 튜닝 1차적 검토 대상
- <mark>FROM절 뒤에 위치</mark>
- 조건식 구성
    - 칼럼명(보통 조건식 좌측)
    - 비교 연산자
    - 문자, 숫자, 표현식(보통 조건식 우측)
    - 비교 칼럼명(JOIN 사용시)

```plsql
SELECT [DISTINCT/ALL] 칼럼명 [ALIAS명]
FROM 테이블명
WHERE 조건식;
```

## 2. 연산자의 종류

1. **비교 연산자**(부정 비교 연산자 포함)
    - `=`, `>`, `>=`, `<`, `<=`
    - 부정 비교 연산자: `!=`, `^=`, `<>`(ISO표준, 같지 않다), `NOT 칼럼명 =`(같지 않다), `NOT 칼럼명 >`(크지 않다)
2. **SQL 연산자**(부정 SQL 연산자 포함()
    - `BETWEEN a AND b`: a와 b의 값 사이의 값(a, b 값 포함)
    - `IN (list)`: 리스트에 있는 값 중 하나라도 일치
    - `LIKE` ‘비교문자열’: 비교 문자열과 형태가 일치(%, _ 사용)
    - `IS NULL`: NULL값을 가짐
    - 부정 SQL 연산자: `NOT BETWEEN a AND b`, `NOT IN (list)`, `IS NOT NULL`
3. **논리 연산자**
    - `AND`: 둘 다 참이면 참
    - `OR`: 하나만 참이면 참
    - `NOT`: 반대 결과 돌려줌
4. **연산자 우선순위**

    | 1 | () |
    | --- | --- |
    | 2 | 비교 연산자, SQL 연산자 |
    | 3 | NOT 연산자 |
    | 4 | AND |
    | 5 | OR |

## 3. 비교 연산자

- `=`, `>`, `>=`, `<`, `<=`
- CHAR, VARCHAR2 변수는 작은 따옴표(’’)로 묶어 비교
- NUMERIC은 인용부호X, 숫자로 변환 가능한 문자열은 자동으로 숫자 타입으로 바뀌어 비교
- 문자 유형 비교 방법
    1. 양쪽이 모두 CHAR
        - 길이가 다른 경우, <mark>작은 쪽이 공백으로 길이를 맞춰 비교</mark>
        - 서로 다른 문자가 나올 때까지 비교
        - 달라진 첫 번째 문자의 값에 따라 크기 결정
        - <mark>문자 끝 공백 수만 다르면 같은 값으로 결정(ex. ‘AA’ = ‘AA&nbsp;&nbsp;&nbsp;&nbsp;‘)</mark>
    2. 한 쪽이 VARCHAR
        - 서로 다른 문자가 나올 때까지 비교한다.
        - 길이가 다르면 짧은 것이 끝날 때까지 비교 후, 길이가 긴 것이 크다고 판단
        - 길이가 같고, 다른 것이 없으면 같다고 판단
        - VARCHAR은 NOT NULL까지의 길이로, <mark>공백도 문자로 취급(ex. ‘AA’ ≠ ‘AA&nbsp;&nbsp;&nbsp;&nbsp;‘)</mark>
    3. 상수값과 비교
        - 상수 쪽을 변수 타입과 동일하게 바꾸고 비교

## 4. SQL 연산자

- 모든 데이터 타입에 대한 연산 가능
    - `BETWEEN a AND b`: a와 b의 값 사이의 값(a, b 값 포함)
  
        <div class="col-2-container align-center" markdown="1">
        <div class="col-2-item" markdown="1">
        
        ```plsql
        SELECT SINIGAMI_NAME, HEIGHT
        FROM 호정대
        WHERE HEIGHT BETWEEN 180 AND 190;
        ```
        
        </div>
        <div class="col-2-item" markdown="1">
        
        ![image.png](/assets/images/posts_img/sql/sql-basic/sql-48.png)
        
        </div>
        </div>

    - `IN (list)`: 리스트에 있는 값 중 하나라도 일치
  
        <div class="col-2-container align-center" markdown="1">
        <div class="col-2-item" markdown="1">
      
        ```plsql
        SELECT SINIGAMI_NAME, DEPARTMENT, HEIGHT
        FROM 호정대
        WHERE (DEPARTMENT, HEIGHT) 
        		IN (('11번대', 202),('5번대',176));
        ```
        </div>
        <div class="col-2-item" markdown="1">
        
        ![image.png](/assets/images/posts_img/sql/sql-basic/sql-49.png)
        </div>
        </div>
      
    - `LIKE` ‘비교문자열’: 비교 문자열과 형태가 일치(%, _ 사용)
        - WildCard  사용 가능(두 개 조합 가능)
            - `%`: 0개 이상의 어떤 문자
            - `_`: 1개인 단일 문자

        <div class="col-2-container align-center" markdown="1">
        <div class="col-2-item" markdown="1">
      
        ```plsql
        SELECT SINIGAMI_NAME, HEIGHT
        FROM 호정대
        WHERE HEIGHT LIKE '18_';
        ```
        </div>
        <div class="col-2-item" markdown="1">
      
        ![image.png](/assets/images/posts_img/sql/sql-basic/sql-50.png)
        </div>
        </div>
    
    - `IS NULL`: NULL값을 가짐
        - NULL값은 비교 불가 → FALSE 리턴 ⇒ <mark>NULL 값의 비교 연산은  IS NULL, IS NOT NULL 사용</mark>

        <div class="col-2-container align-center" markdown="1">
        <div class="col-2-item" markdown="1">
      
        ```plsql
        SELECT SINIGAMI_NAME
        FROM 호정대
        WHERE DEPARTMENT IS NULL;
        ```

        <div class="col-2-item" markdown="1">

## 5. 논리 연산자

- `AND`: 둘 다 참이면 참
- `OR`: 하나만 참이면 참 → IN (list)와 같음
- `NOT`: 반대 결과 돌려줌
- 연산자 우선순위 → (), NOT, AND, OR을 고려하여 작성
