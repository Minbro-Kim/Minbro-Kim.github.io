## 1. 조인 개요

- JOIN은 <mark>두 개 이상의 테이블들을 연결해 데이터를 출력하는 것</mark>
- JOIN은 관계형 데이터베이스의 가장 큰 장점이자 핵심기능
- 일반적으로 PK와 FK값의 연관에 의해 조인 성립
    - 논리적인 값들의 연관만으로 조인 성립 가능
- <mark>FROM 절에 여러 테이블이 나열되어도 단 두 개의 집합 간에만 조인 발생</mark>
    - 조인 순서는 DBMS(옵티마이저)에 의해 결정
    - ex. A,B,C → A와 B 조인 결과 집합을 C와 조인
- 정규화를 위해 필요
- 시스템 자원 부족이나 과다한 응답시간 지연을 발생시키는 중요 원인이 되므로 조인 조건 신중히 작성

## 2. EQUI JOIN (등가)

```sql
SELECT 테이블1.칼럼명, 테이블2.칼럼명,...
FROM 테이블1, 테이블2
WHERE 테이블2.칼럼명 = 테이블1.칼럼명 --WHERE 조건 기술
```

- 두 개의 테이블 간에 칼럼 값들이 서로 정확하게 일치하는 경우 사용
- 대부분 PK↔ FK 관계 이용
- <mark>JOIN 조건 → WHERE절에 ‘=’ 연산자를 이용하여 표현</mark>
    - ANSI/ISO SQL 표준방식은 INNER JOIN과 ON절 이용)
- 가독성을 위해 칼럼명이 유일한 경우에도 테이블명 또는 ALIAS명 기술 권장
- <mark>조인 조건 최소 개수 = 조인하는 테이블 개수 - 1</mark>

## 3. Non EQUI JOIN (비등가)

- Non EQUI JOIN은 <mark>두 개의 테이블 간에 논리적인 연관관계를 갖고 있으나, 칼럼 값들이 서로 일치하지 않는 경우 사용</mark>
- ‘=’가 아닌 <mark>다른 연산자(BETWEEN, >, < 등)을 사용</mark>해 JOIN 수행
- 데이터 모델에 따라 불가능한 경우 있음

## 4. OUTER JOIN (외부 조인)

- EQUI/Non EQUI JOIN은 조인 조건이  참이 행들만 반환하는 INNER JOIN(내부 조인)

→ OUTER JOIN은 <mark>조인 조건을 만족하지 않는 행들도 함께 반환</mark>

- <mark>조인에 실패한 행은 기준 칼럼의 값이 표시되고, 그 외 칼럼들은 NULL로 표시</mark>
- (+) 로 OUTER JOIN 표시
    - <mark>(+) 표시의 반대편 테이블이 OUTER JOIN의 기준 테이블(모든 행 출력)</amrk>
    - ex. 테이블2.칼럼명(+) = 테이블1.칼럼명 ⇒ 테이블1의 모든 행을 출력

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
SELECT A.PLAYER_NAME, B.REGION
FROM 선수 A, 배구팀 B
WHERE B.TEAM_NAME(+) = A.TEAM_NAME;
```

- 보쿠토의 팀은 NULL이지만 OUTER JOIN으로 선수의 모든 행을 가져오고, 조인조건을 만족하지 못한 보쿠토 행의 지역은 NULL로 표시
