## 1. 내장 함수 개요

- 함수(Function): 입력 값의 수와 관계없이 <mark>출력은 하나(M:1 관계)</mark>
    - 내장함수(Built-in Function): 벤더에서 제공하는 함수, 벤더별로 차이
        - <mark>단일행 함수(Single-Row Function)</mark>
        - 다중행 함수(Multi-Row Function)
            - 집계 함수(Aggregate Function)
            - 그룹 함수(Group Function)
            - 윈도우 함수(Window Function)
    - 사용자 정의 함수(User Defined Function): 사용자가 직접 정의하는 함수
- 단일행 함수(Single-Row Function)
    - 단일행 내에 있는 하나의 값 또는 여러 값이 입력 인수
    - <mark>문자형, 숫자형, 날짜형, 변환형, Null관련 함수로 나뉨</mark>
    - SELECT, WHERE, ORDER BY절에 사용 가능
    - 각 행에 개별적으로 작용하여  조작 결과 반환
    - <mark>여러 인자(Argument)를 입력해도 하나의 결과 반환</mark>
    - 함수의 인자로 상수, 변수, 표현식 사용 가능
    - <mark>함수 중첩 가능</mark>

## 4. 날짜형 함수

- DATE 타입 값 연산
- DATE 변수는 데이터베이스 내부적으로 세기, 연, 월, 일, 시, 분, 초와 같은 숫자 형식으로 변환하여 저장

  → <mark>연산가능</mark>

  | 날짜 +- 숫자 | 날짜 | 날수 +- 숫자 |
      | --- | --- | --- |
  | 날짜1 - 날짜2 | 날짜수 | 일수 |
  | 날짜 + 숫자/24 | 날짜 | 날짜+시간 |

<br>

<div class="col-2-item" markdown="1">

- `SYSDATE` : 현재 날짜, 시각 출력

```plsql
SELECT SYSDATE
FROM DUAL;
```

![image.png](/assets/images/posts_img/sql/sql-basic/sql-34.png)

    - SQL Server: `DATEPART(YEAR|MONTH|DAY,d)`

## 5. 변환형 함수

- 특정 데이터 타입을 다양한 형식으로 출력
    - 명시적(Explicit) 데이터 유형 변환: 변환형 함수 사용
    - 암시적(Implicit) 데이터 유형 변환: 데이터베이스가 자동으로 데이터 유형을 변환하여 계산

      → 성능저하 및 에러 가능성

<div class="col-2-container" markdown="1">
<div class="col-2-item" markdown="1">


- `TO_NUMBER(문자열)`: 문자열 → 숫자
    - SQL Server: `CAST(expression AS data_type [(length)])`: 표현 → 목표 데이터 유형

```plsql
SELECT TO_NUMBER('0123')
FROM DUAL;
```

![image.png](/assets/images/posts_img/sql/sql-basic/sql-37.png)

- `TO_DATE(문자열 [, FORMAT])`: 문자열 → 포맷형태 날짜타입
    - SQL Server: `CONVERT(data_type [(length)], expression [, style])`

```plsql
SELECT TO_DATE('23.07.07')
FROM DUAL;
```

![image.png](/assets/images/posts_img/sql/sql-basic/sql-38.png)

</div>
<div class="col-2-item" markdown="1">


- `TO_CHAR(숫자|날짜 [, FORMAT])`: 숫자 → 포맷형태 문자열 타입
    - SQL Server: `CONVERT(data_type [(length)], expression [, style])`

```plsql
SELECT TO_CHAR(SYSDATE, 'YYYY/MM/DD') 날짜,
       TO_CHAR(SYSDATE, 'YY.MON.DAY') 문자형
FROM DUAL;
```

![image.png](/assets/images/posts_img/sql/sql-basic/sql-39.png)

## 6. CASE 표현

- IF-THEN-ELSE 논리와 유사 → SQL 비교 연산 기능 보완

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
--IF-THEN-ELSE-END
IF SAL > 2000
    THEN REVIESED_SALARY = SAL
	ELSE REVISED_SALARY = 2000
END IF
```

</div>
<div class="col-2-item" markdown="1">

```plsql
--CASE 표현
SELECT ENAME
        , CASE
            WHEN SAL > 2000 THEN SAL
            ELSE 2000
        END AS REVISED_SALARY
FROM EMP;
```

</div>
</div>

- CASE Expression이지만 함수와 유사 → <mark>중첩해서 사용 가능</mark>

### 1. Simple Case Expression
  - SIMPLE_CASE_EXPRESSION 조건
    - `O → THEN`
    - `X → ELSE`
  - <mark>CASE 다음 칼럼이나 표현식 사용</mark>
  - 다음 WHEN절에서 `EQUI(=)`조건만 사용할 때 유용
  - <mark>Oracle의 DECODE 함수와 동일</mark>

  ```plsql
  CASE 컬럼/표현식
      SIMPLE_CASE_EXPRESSION 조건
      [ELSE 디폴트값]
  END
  ```
<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
SELECT SINIGAMI_NAME,
        CASE SINIGAMI_NAME
            WHEN '켄파치' THEN '대장'
            WHEN '신지' THEN '대장'
            WHEN '이치고' THEN '사신대행'
            ELSE '부대장'
        END AS 직위
FROM 호정대;
```

### 2.  Searched Case Expression

- SERCHED_CASE_EXPRESSION 조건
  - `O → THEN`
  - `X → ELSE`

- <mark>CASE 다음 칼럼이나 표현식 사용X</mark>
- 다음 WHEN절에서 `여러 조건(>, <, = 등)`을 이용

```plsql

    SERCHED_CASE_EXPRESSION 조건

```

```plsql
        ELSE '180 미만'
    END AS 키
```

## 7. NULL 관련 함수

- NULL 특성
    - <mark>아직 정의 되지 않은 값, 0이나 공백과 다름</mark>
    - NOT NULL, PRIMARY KEY로 정의되지 않은 모든 데이터 유형은 NULL값 포함 가능
    - NULL의 연산 결과는 NULL → NVL/ISNULL 함수로 데이터 처리

### 가. NVL/ISNULL 함수

- `NVL(표현식1, 표현식2)`
    - 표현식1이 NULL이면 표현식2 출력
    - 표현식1과 표현식2의 데이터 타입이 같아야 함
        - 숫자 → 0, 문자 → x로 주로 변환
    - NULL관련으로 가장 많이 사용
    - 다중행 함수에서는 불필요한 부하 가능으로 사용X
    - SQL Server: `ISNULL(표현식1, 표현식2)`
    - MySQL: `IFNULL(표현식1, 표현식2)`

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
SELECT SINIGAMI_NAME,
        NVL(DEPARTMENT, '사신대행') 
        AS 소속
FROM 호정대;
```

### 나. NULL과 공집합

- 공집합: 조건에 맞는 데이터가 한 건도 없는 경우 → NVL/ISNULL로 처리 불가(NULL값이 아니기 때문)

  → 집계함수 사용(공집합일 경우 NULL 반환)

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">


### 다. NULLIF

- `NULLIF(표현식1, 표현식2)`
    - 표현식1 = 표현식2 → NULL
    - 표현식1 ≠ 표현식2 → 표현식1
    - 특정 값을 NULL로 바꿀 때 유용

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

```plsql
SELECT SINIGAMI_NAME, 
        NULLIF(DEPARTMENT, '11번대')
FROM 호정대;
```

### 라. COALESCE 함수

<div class="col-2-container align-center" markdown="1">
<div class="col-2-item" markdown="1">

- `COALESCE(표현식1, 표현식2,...)`
  - <mark>NULL이 아닌 최초의 표현식 반환</mark>
  - <mark>모두 NULL이면 NULL 반환</mark>
  - 중첩된 CASE 문장으로 표현 가능

```plsql
SELECT SINIGAMI_NAME, 
        COALESCE(DEPARTMENT, 
        '그냥 '||SINIGAMI_NAME) 소속
FROM 호정대;
```

- CASE문으로 표현

```plsql
SELECT SINIGAMI_NAME,
     CASE
       WHEN DEPARTMENT IS NOT NULL THEN DEPARTMENT
       ELSE (CASE
                WHEN SINIGAMI_NAME IS NOT NULL
                        THEN '그냥 '||SINIGAMI_NAME
                ELSE NULL
            END)
    END AS 소속
FROM 호정대;
```
