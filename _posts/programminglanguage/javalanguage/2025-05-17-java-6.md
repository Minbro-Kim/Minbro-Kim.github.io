## HashMap
### 1. 개념
- `Key-Value`로 저장
- 내부적으로 해쉬테이블 사용
- Key를 사용하여 값을 검색하는 자료구조 (Key만 저장 -> `HashSet`)
- 키는 중복 불가, 값은 중복 가능
- 순서를 보장 X (LinkedHashMap은 순서 보장)

### 2. 선언
```java
HashMap<String, String> mp = new HashMap<>();
// 권장 방식: 인터페이스로
Map<String, String> map = new HashMap<>();
```

### 3. 주요 메소드

| 메서드                   | 설명            | 평균/최악          |
|----------------------------|----------------------------|-------------------|
| `put(k, v)`           | 데이터 삽입 또는 수정(이미 해당 키 O)  | O(1)/O(N)    |
| `get(k)`           | 데이터 조회 (k없으면 null)  | O(1)/O(N)    |
| `containsKey(k)`           | 일치하는 key (boolean)   | O(1)/O(N)    |
| `containsValue(v)` | 해당 값 존재 여부 반환         | O(N)/O(N)    |
| `size()`               | 키-값 쌍의 개수 반환          | O(1)/O(1)    |
| `remove(k)`          | 해당 키 삭제               | O(1)/O(N)    |
| `clear()`              | 모든 항목 삭제              | O(N)/O(N)    |
| `isEmpty()`            | 맵이 비었는지 확인            | O(1)/O(1)    |
| `keySet()`             | 키들만 `Set`으로 반환        | O(N)/O(N)    |
| `values()`             | 값들만 `Collection`으로 반환 | O(N)/O(N)    |
| `entrySet()`           | `Map.Entry`의 집합 반환, 반복문에 사용  | O(N)/O(N)    |

#### 코드
1. `put(k, v)`
```java
		map.put("하이큐","쿠로오");
		map.put("헌터헌터", "히소카");
		System.out.println(map);\
    // put으로 값 수정
		map.put("하이큐", "츠키시마");
		System.out.println(map);
```
```
    {헌터헌터=히소카, 하이큐=쿠로오}
    {헌터헌터=히소카, 하이큐=츠키시마}
```
2. `get(k)`
```java
        System.out.println("하이큐에는 "+map.get("하이큐")+"가 있다");
        // 없는 key로 조회 -> null
        System.out.println("주술회전은 "+map.get("주술회전")+"이 없는데");
```
```
        하이큐에는 츠키시마가 있다
        주술회전은 null이 없는데
```
3. `containsKey(k)`
```java
        if(map.containsKey("하이큐")) {
			System.out.println("하이큐가 있다...!");
		}
```
```
        하이큐가 있다...!
```
4. `containsValue(v)`
```java
    if(!map.containsValue("나기")) {
			map.put("블루록", "나기");
			System.out.println(map);
		}
```
```
        {헌터헌터=히소카, 블루록=나기, 하이큐=츠키시마}
```
5. `size()`
```java
        System.out.println("현재 개수는 "+map.size()+"개다!");
```
```
        현재 개수는 3개다!
```
6. `remove(k)`
```java
		System.out.println(map);
		map.remove("하이큐");
		System.out.println(map);
```
```
        {헌터헌터=히소카, 블루록=나기, 하이큐=츠키시마}
        {헌터헌터=히소카, 블루록=나기}
```
7. `clear()`
```java
        System.out.println(map);
		map.clear();
		System.out.println(map);
```
```
        {헌터헌터=히소카, 블루록=나기}
        {}
```
8. `isEmpty()`
```java
		if(map.isEmpty()) {
			map.put("NCIS", "디노조" );
			map.put("Bones", "부스");
			map.put("newsroom", "하퍼");
		}
		System.out.println(map);
```
```
        {Bones=부스, NCIS=디노조, newsroom=하퍼}
```
9.  `keySet()`
```java
		// type 확인
		System.out.println(map.keySet().getClass());
		System.out.println(map.keySet());
		// keySet은 참조 형태기 때문에 key삭제시 hashMap에서도 삭제됨
		Set<String> keys = map.keySet();
		keys.remove("NCIS");
		System.out.println(keys);
		System.out.println(map);
```
```
        class java.util.HashMap$KeySet
        [Bones, NCIS, newsroom]
        [Bones, newsroom]
        {Bones=부스, newsroom=하퍼}
```
10. `values()`
```java
		Collection<String> vals = map.values();
		System.out.println(vals);
```
```
        [부스, 하퍼]
```
11. `entrySet()`
```java
		Set<Map.Entry<String, String>> mapE = map.entrySet();
		System.out.println(mapE);
		
		//반복문에 사용
		for(Map.Entry<String, String> m : map.entrySet()) {
			System.out.println("제목: " + m.getKey());
			System.out.println("캐릭터: "+m.getValue());
		}
```
```
        [Bones=부스, newsroom=하퍼]
        제목: Bones
        캐릭터: 부스
        제목: newsroom
        캐릭터: 하퍼
```

### 4. getOrDefault() & putIfAbsent()

1. `getOrDefault(k, 기본값)`
   - 없을 때 기본값
   - `containsKey`->`get`을 한 번에 처리
   - O(1)/O(N) 
    ```java
        System.out.println(map.getOrDefault("westwing", "없다 요놈아!"));
    ```
    ```
        없다 요놈아!
    ```
2. `putIfAbsent(k, v)`
    - k 없을 때만 삽입
    - `put`으로 기존 값 수정되는 것 방지
    - 조건부 삽입 단순화
    - O(1)/O(N) 
    ```java
        map.putIfAbsent("Bones", "하진스");
        System.out.println(map);
    ```
    ```
        {Bones=부스, newsroom=하퍼}
    ```
