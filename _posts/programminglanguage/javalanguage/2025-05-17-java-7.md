## HashSet
### 1. 개념
- `HashMap`을 내부적으로 사용해서 구현된 집합 자료구조
- 중복 불가, 순서 X, null 한 개 저장 가능
- 내부적으로 `HashMap<E, Object>`로 구현
- `add(E e)`는 내부적으로 `map.put(e, DUMMY_VALUE)`처럼 동작

### 2. 선언
```java
        HashSet<String> st = new HashSet<>();
        // 권장: 인터페이스 활용
        Set<String> set = new HashSet<>();
```

### 3. 주요 메소드

| 메서드                   | 설명            | 평균/최악       |
|----------------------------|----------------------------|---------|
| `add(E e)`           | 요소 추가 (중복이면 false 반환)   | O(1)/O(N)   |
| `contains(Object o)` | 해당 요소 포함 여부 확인          | O(1)/O(N)   |
| `remove(Object o)`   | 요소 제거                   | O(1)/O(N)   |
| `clear()`            | 모든 요소 제거                | O(N)/O(N)   |
| `isEmpty()`          | 비어 있는지 확인               | O(1)/O(1)   |
| `size()`             | 요소 개수 반환                | O(1)/O(1)   |
| `iterator()`         | 반복자 반환 (향상된 for문 등에 사용) | O(1)/O(N)   |

#### 코드
1. `add(E e)`
```java
		set.add("츠키시마");
		set.add("카게야마");
        set.add("카게야마"); // 중복 무시
		System.out.println(set);
```
```
        [츠키시마, 카게야마]
```
2. `contains(o)`
```java
		if(set.contains("카게야마")) {
			System.out.println("제왕 있음!");
		}
```
```
        제왕 있음!
```
3. `remove(o)`
```java
		set.remove("카게야마");
		System.out.println(set);
```
```
        [츠키시마]
```
4. `clear()`
```java
		set.clear();
		System.out.println(set);
```
```
        []
```
5. `isEmpty()`
```java
		if(set.isEmpty()) {
			set.add("쿠로오");
			set.add("켄마");
			System.out.println("비어있던거 채움!!\n"+set);
		}
```
```
        비어있던거 채움!!
        [쿠로오, 켄마]
```
6. `size()`
```java
        System.out.println("몇개 들어있냐면..."+set.size()+"개!");
```
```
        몇개 들어있냐면...2개!
```
7. `iterator()`
```java
		// 일반 반복, for-each문
		for(String s : set) {
			System.out.println("캐릭터: "+s);
		}
		
		// 삭제 등이 필요할 때 - Iterator
		Iterator<String> it = set.iterator();
		while(it.hasNext()) {
			System.out.println(it.next());
			it.remove();
			System.out.println(set);
		}
```
```
        캐릭터: 쿠로오
        캐릭터: 켄마
        쿠로오
        [켄마]
        켄마
        []
```
