## Optional
### 1. 개념
- 값의 존재유무가 확실하지 않을 때 사용하는 컨테이너
- NullPointerException 방지

### 2. 생성

| 메서드                      | 설명                       |
|----------------------------|----------------------------|
| `Optional.of(T)`         | null이 아니어야 함, null이면 NPE |
| `Optional.ofNullable(T)` | null 가능                  |
| `Optional.empty()`       | 빈 Optional 생성            |

#### 코드

```java
Optional<String> opt1 = Optional.of("Hello");        // null이 아닌 값
Optional<String> opt2 = Optional.ofNullable(null);   // null일 수도 있음
Optional<String> opt3 = Optional.empty();            // 비어 있는 Optional
```

### 3. 값 꺼내기

| 메서드                   | 설명            |
|----------------------------|----------------------------|
| `get()`           | 값 반환, 비어있는 경우 NPE       |


### 4. <mark>NPE 없이 값 꺼내기</mark>

| 메서드                   | 설명            |
|----------------------------|----------------------------|
| `orElse(T)`           | 기본값 반환        |
| `orElseGet(Supplier)` | 지연 계산된 기본값 제공 |
| `orElseThrow()`       | 예외 던짐         |

#### 코드

```java
// 값이 있으면 반환, 없으면 "기본값"
String name = opt.orElse("츠키시마");
System.out.println(name);

// 값이 있으면 반환, 없으면 함수 실행해서 반환
String name2 = opt.orElseGet(() -> "츠키시마" + "카라스노");
System.out.println(name2);

// 값이 없으면 예외 던지기
String name3 = opt.orElseThrow(() -> new IllegalArgumentException("없음"));
```

### 5. 값 존재 여부 확인

| 메서드                   | 설명            |
|------------------------|------------------|
| `isPresent`           | `true` - 존재        |
| `isEmpty`           | `true` - 부재, java11부터 지원     |


#### 코드

```java
if (!opt.isPresent()) {
		    System.out.println("비어있구나!");
		}
```
