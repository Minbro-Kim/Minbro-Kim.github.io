## Array, ArrayList, Arrays$ArrayList 

### 비교

  | 항목         | `Array`         | `ArrayList`          | `Arrays$ArrayList`        |
  |------------|-------------------|----------------------|---------------------------|
  | **소속 패키지** | `java.lang`       | `java.util`          | `java.util.Arrays` 내부 클래스 |
  | **크기 변경**  | X                | O                 | X                       |
  | **제네릭 지원** | X       | O (`List<T>`)     | O (`List<T>`)          |
  | **속도**     | 빠름   |  보통      | 빠름 (배열을 감싼 형태)          |
  | **기본 메서드** | 없음 (`length`만 있음) | 많음 (`add`, `remove`) | 일부만 지원 (`set`, `get`)     |
  | **사용 용도**  | 기본적인 데이터 저장       | 동적 리스트               | 배열 → 리스트 변환 시 편리          |
  | **특이사항**   | `new`로 직접 생성      | 내부적으로 배열 사용          | 원본 배열의 **뷰(view)** 역할(코드 참고)   |


#### 코드
  ``` java
  // 1) ArrayList
  List<String> test1 = new ArrayList<>(Arrays.asList("곤","키르아","레오리오"));
  System.out.println(test1);
  System.out.println(test1.getClass());
  
  //2) Array
  String[] test2 = {"헌터가 되어서", "헌터 라이센스", "가지고 싶다"};
  System.out.println(Arrays.toString(test2));
  System.out.println(test2.getClass());
  
  //3) Arrays$ArrayList
  List<String> test3 = Arrays.asList("즐거운 일이", "하나도 없다니", "놀라운 일이다");
  System.out.println(test3);
  System.out.println(test3.getClass());
  
  // 배열의 복사본이 아니라,참조
  List<String> test4 = Arrays.asList(test2);
  test2[2] = "팔아서 부자되야지";
  System.out.println(test4);
  ```

  ```plain text
  [곤, 키르아, 레오리오]
  class java.util.ArrayList
  [헌터가 되어서, 헌터 라이센스, 가지고 싶다]
  class [Ljava.lang.String;
  [즐거운 일이, 하나도 없다니, 놀라운 일이다]
  class java.util.Arrays$ArrayList
  [헌터가 되어서, 헌터 라이센스, 팔아서 부자되야지]
  ```

#### [참고] 배열 타입표기

  | 배열 타입        | `getClass()` 출력        | 의미                    |
  |--------------|------------------------|-----------------------|
  | `int[]`      | `[I`                   | `[`는 배열, `I`는 int     |
  | `double[]`   | `[D`                   | `D`는 double           |
  | `String[]`   | `[Ljava.lang.String;`  | `L`은 객체, `String` 클래스 |
  | `int[][]`    | `[[I`                  | 2차원 배열                |
  | `String[][]` | `[[Ljava.lang.String;` | 2차원 문자열 배열            |

### 배열을 리스트로 변환
- 타입이 같은 경우, `Arrays.asList(arr)'로 즉시 변환
- 레퍼 타입으로 변환하는 경우 Stream의 `boxed` 사용
```java
int[] arr = {1, 2, 3};
List<Integer> list = IntStream.of(arr)
                              .boxed()
                              .collect(Collectors.toList());
```

### 리스트를 배열로 변환
- 타입이 같은 경우, `toArray(T[]::new)` 또는 `toArray(new T[0])`사용
- 프리미티브 타입으로 변환하는 경우, Stream의 `mapToInt(Integer::intValue)``mapToDouble(Double::doubleValue)` 사용 후, `toArray()`사용
```java
//Interger -> Integer
List<Integer> list = new ArrayList<>(Arrays.asList(1,2,3,4));
Integer[] arr = list.toArray(new Integer[0]);

//Integer -> int
int[] brr = list.stream().mapToInt(Integer::intValue).toArray();
```
